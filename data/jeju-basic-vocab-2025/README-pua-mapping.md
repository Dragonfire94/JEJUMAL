# PUA → 옛한글 유니코드 매핑 작업 (81개 고유 glyph)

`data/jeju-basic-vocab-2025/source.pdf`에서 PUA(사용자 영역, U+E000–F8FF)
문자로 인쇄된 표제어 425개(초중급만 보면 298개)를 조사한 결과, 실제로는
**고유 glyph가 81개뿐**이라는 걸 확인하고(중복 코드 재사용), 그 81개를
하나씩 판독한 작업 기록.

## 방법 — "298번 풀지 않고 81번만 푼다"

1. `vocab.json`의 모든 항목에서 PUA 문자를 스캔해 **고유 코드포인트 81개**로
   문제를 축소(`data/jeju-basic-vocab-2025/pua-glyph-mapping.json`).
2. PDF 원본 페이지를 8~12배 확대 렌더링해서 각 glyph를 실제 손글씨체
   그대로 크롭 → 5×4 격자 이미지 시트 5장으로 정리해 직접 눈으로 판독.
3. 대부분의 glyph가 **"초성+아래아(+종성)"** 조합이라는 걸 확인. 이건
   제주어가 표준어에서 사라진 아래아 모음을 실제로 보존하고 있어서
   생기는 자연스러운 현상.
4. 판독한 조합을 **중세국어(15~16세기) 문헌에 이미 기록된 형태**와
   대조 — 상당수가 국어사 교과서에도 나오는 유명한 단어와 정확히
   일치해서 교차검증됨(아래 표).
5. 옛한글 조합 렌더링 검증: Noto Sans/Serif CJK KR(OFL 라이선스, 별도
   조사 완료)로 복원한 유니코드를 실제로 다시 그려서 PDF 원본 모양과
   비교(round-trip) — 확인된 것들은 정상적으로 하나의 음절 블록으로
   합성됨.

## 결과: 36개 high / 23개 medium / 22개 low(재검토 필요)

`pua-glyph-mapping.json`에 81개 전체가 있다. 필드:

```jsonc
{
  "pua": "U+F537",            // 원본 PUA 코드
  "reading": "ᄒᆞ루",           // 복원한 옛한글 유니코드 (확정 못한 건 null)
  "confidence": "high",       // high / medium / low
  "note": "...",              // 판단 근거
  "context_form": "...",      // 책에 나온 원래 표기(단독으로는 안 보일 수 있음)
  "context_standard": ["하루"], // 표준어 대응
  "occurrences_in_book": 203, // 책 전체(초중고급)에서 이 코드가 등장한 횟수
  "sample_page": 24           // 판독에 사용한 페이지(0-based PDF 인덱스)
}
```

### high(43개) — 중세국어 문헌과 정확히 일치, PDF 크롭 직접 재확인, 또는 자체 사전·말뭉치로 재검증됨

예: `ᄀᆞᆮ다`(말하다), `ᄂᆞᆯ다`(날다), `ᄂᆞᆷ`(남), `ᄃᆞᆯ`(달), `ᄉᆞᆯ`(살),
`ᄌᆞᆷ`(잠), `ᄒᆞ루`(하루), `ᄑᆞᆯ`(팔), `ᄊᆞᆯ`(쌀) 등 36개는 국어사 지식으로
이미 검증된 단어라 **독립적인 제3의 근거(중세국어 문헌 기록)로
뒷받침됨.**

나머지 7개는 원래 medium이었다가, **아래아의 제주 현대 반사음 규칙
("아래아→ㅗ"가 가장 흔함)으로 현대 표기 후보를 만들어 AI Hub
말뭉치·자체 사전과 대조**해서 승급시켰다:

| PUA | 옛한글 복원 | 현대 표기 확인 | 근거 |
|---|---|---|---|
| U+E38B | ᄃᆞᆰ(닭) | 돍 | 말뭉치 14회, 뜻 정확히 일치 |
| U+E97D | ᄉᆞ나이(사나이) | 소나이 | 말뭉치 44회 이상 |
| U+E564 | ᄆᆞᆮ이(맏이) | 몯이 | 말뭉치 1회지만 뜻 정확 일치 |
| U+E994 | ᄉᆞᆼ키(푸성귀) | 송키 | 말뭉치 26회 이상 |
| U+F545 | ᄒᆞᆷ치(한꺼번에) | 홈치 | 말뭉치 13회 |
| U+E64F | ᄇᆞᆯ르다(바르다) | 발르다 | 자체 사전에 이름·뜻 정확 일치 항목 존재 |
| U+E71E | ᄈᆞᆯ래(빨래) | 빨래 | 말뭉치 다수 — 이 단어는 아래아가 현대에도 표준형과 같은 소리로 남은 듯 |

### medium(16개) — 모양+뜻은 통하는데 자음 종류가 애매, 재검증에서도 확정 못함

예: `ᄀᆞᆫ`(간 추정), `ᄇᆞ름`(바람 추정), `ᄉᆞᆷ다`(때다 추정 — 말뭉치에
1회 나오지만 근거가 약해 medium 유지). 초성/종성 후보를 하나로
좁혔지만 자체 사전·말뭉치 재대조에서도 노이즈만 나오거나(단순
부분일치, 뜻이 다른 동음이의어) 확증을 못 찾았다. 최종 반영 전에
사람이 PDF 원본을 보고 확정하는 게 안전.

### low(22개) — 재검토 필요

주로 **첩어(같은 음절 반복 — 까닥까닥, 깨끗하다, 탄탄하다 등)**나
**복합어(독+PUA+릅=무릎, 애+PUA+다=애끓다 등)**처럼 한 단어에 PUA가
여러 개 겹치거나 주변 글자와 뒤섞여서, 크롭 이미지만으로 자모를
하나씩 분리하기 애매한 경우다. 이 22개는 **사람이 PDF 원본을 보면서
확정**하거나, 더 정밀한 크롭(글자 하나하나 좌표를 다시 잡는 식)으로
재작업해야 한다.
