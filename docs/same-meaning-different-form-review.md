# same_meaning_different_form(111개) 검토: 진짜 정리 대상은 14개뿐

Fable의 크로스체크 `same_meaning_different_form`(111개)는 "2025년 책의
후보 단어가, 우리 기존 1000단어 중 같은 표준어 뜻을 가진 단어와
표기가 다르다"고 잡아낸 목록이다. 이번에 사용자 요청대로 "기존 단어
표기가 지역 변이형인지 오류인지" 검토했다.

## 1. 111개 중 상당수는 이미 손 안 대도 되는 상태

- **61개**: 책 후보 단어가 이미 지난 라운드(1000단어 최종 확정)에서
  신규 lexeme로 앱에 들어가 있음.
- **54개**: Fable이 지목한 기존 단어가 이번 최종 확정 때 이미
  제거됨(confirmed·rare가 아니고 책에도 없어서 드롭된 unconfirmed
  654개 중 하나였음) — 더 이상 겹칠 일이 없음.
- **둘 다 겹치는 경우(신규 추가 + 기존 유지)가 33개** — 이게 진짜
  "같은 뜻의 두 표기가 앱에 동시에 존재하는" 상황이라 검토가 필요한
  대상이다.

## 2. 33개를 4가지로 분류

### (A) 표기 방식 차이일 뿐, 사실 같은 단어 — 3개, 조치 불필요

우리 기존 콘텐츠가 용언 어간을 `나끄(낚으)다`처럼 괄호로 두 어간을
같이 적는 관례를 쓰는데, 신규 항목은 그 괄호를 안 쓰고 어간 하나만
적어서(`나끄다`) 겹치는 것처럼 보였을 뿐이다.

| 뜻 | 기존 | 신규 |
|---|---|---|
| 낚다 | 나끄(낚으)다 | 나끄다 |
| 높다 | 노프(높으)다 | 노프다 |
| 맡다 | 마트(맡으)다 | 마트다2 |

### (B) 둘 다 말뭉치로 확인됨 — 진짜 방언 변이형, 그대로 둬도 됨 — 10개

두 표기 모두 실제 사용 증거(말뭉치)가 있다. 같은 뜻을 가진 진짜
변이형(예: 고냉이/고넹이, 괴기/궤기)이거나, 아예 다른 단어인데
뜻만 같은 경우(가운데=셋/가운디)다. 둘 다 실증됐으니 억지로 하나를
없앨 이유가 없다.

|---|---|---|
| 가운데 | 셋 | 가운디 |
| 고양이 | 고냉이 | 고넹이 |
| 고기/물고기 | 괴기 | 궤기 |
| 조카 | 조캐 | 조케 |
| 데 | 듸 | 디 |
| 너희 | 너내 | 너네 |

기존·신규 둘 다 rare/unconfirmed라서 어느 쪽도 우위가 없다. 지금
단계에서 손대면 근거 없이 하나를 편애하는 셈이라 그대로 둔다.

| 뜻 | 기존 | 신규 |

### (D) 한쪽만 확인됨 — 14개, **진짜 정리 대상**

쪽을 없애거나 최소한 "덜 흔한 변이형"으로 표시하는 게 합리적이다.

## 3. 결론 및 제안

14개 중:
- **8개는 "신규(2025책) 쪽이 근거 약한 중복"** → 없애도 손해 없음(강아지·이마·붙다·개미·뚜껑·뼈 6개 + 데이터 이상 의심되는 담그다·싫다 2개)
- **4개는 오히려 "기존 쪽이 근거 약한 중복"** → 신규가 더 신뢰할 만함(펴다·도마·매일·마늘)
- **2개는 삭제 보류**(소=쉐, 줍다=줏다) — unconfirmed 판정이 말뭉치 매칭 로직의 한계 때문일 수 있어서, 없애기 전에 우리 자체 사전이나 다른 방식으로 한 번 더 확인하는 게 안전.

이 정리 작업(중복 제거·주표기 교체)을 실제로 실행할지, 어느 방향으로
할지 사용자 확인 후 진행하는 게 맞다고 판단해 이번엔 분석까지만
하고 데이터는 아직 안 건드렸다.
