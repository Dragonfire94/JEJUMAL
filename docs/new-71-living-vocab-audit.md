# 3C-1 — 신규 71개 생활 제주어 감사

> 3C-1.1에서 방법론을 보강해 재검증했다. 이 PR은 감사 원장과 재현 스크립트만 바꾸며 production content는 변경하지 않는다.

## 방법론 보강

- 이전의 판정 Set 출력 방식 대신, 각 행에 수동 판정의 개별 근거와 평가축을 남겼다.
- `usageEvidence`는 최종 판정과 무관하게 뜻풀이와 통하는 AI Hub 토큰 매핑 및 줄 정렬이 확인된 생활방언 자료만으로 계산한다.
- `score`는 사용 근거·생활 효용·제주 고유성·문화 중요성·중복 위험·공식 등급만으로 계산한다. `decision`은 score 계산에 쓰지 않는다.
- 71개 전부에 `semanticDuplicateReview`를 기록했다. 자동 문자열 유사도는 탐색에만 썼고, 최종 상태는 뜻풀이와 기존 content를 대조해 수동으로 검토했다.
- AI Hub `tokens.json`에는 발화 ID/원문이 없으므로, 뜻풀이에 맞는 매핑 집계는 기록하되 개별 원문 문맥을 확보했다고 주장하지 않는다.

나머지 70개는 판정이 유지됐다. 이것은 기존 숫자를 지키기 위한 결과가 아니라, 근거·평가축·의미 중복 검토를 분리한 뒤에도 수동 검토 결론이 바뀌지 않았다는 뜻이다.

| usageEvidence | count |

| STRONG | 2 |
| MEDIUM | 2 |

`NONE`은 사어 판정이 아니라, 이 감사가 이용한 두 자료에서 해당 의미의 검증된 사용을 확인하지 못했다는 뜻이다. `CULTURE_ADD`와 `HOLD`에 자동으로 WEAK를 부여하지 않는다.

CORE_ADD의 뜻풀이 대조 기반 사용 근거는 `요자기`만 STRONG이고, `삼춘`·`그추룩`·`이추룩`·`저추룩`·`봅서`·`나냥으로`는 이 자료에서 원문 문맥을 추적할 수 없어 NONE이다. 따라서 이 CORE 판정은 사용 빈도를 과장하지 않고, 아래의 개별 생활 효용 검토에 기반한다.

## DO_NOT_ADD

말젯딸·말젯아덜·말젯아방·말젯어멍·셋딸·셋아덜은 매우 좁은 친족 서열어, 설남은은 좁은 수사 슬롯, 조고만하다·쪼끌락하다 계열은 기존 작은 정도 표현과의 중복 위험, 매기독닥은 특정 상황 감탄사라는 점을 각 행에 기록했다. 이는 단어가 존재하지 않거나 가치가 없다는 판정이 아니라 현 핵심 학습 앱의 우선순위 판단이다.
